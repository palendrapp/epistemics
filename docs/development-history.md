# Development history and initial publication

The project was developed in an uncommitted local workspace on **19 September 2026**. Its first public Git history was assembled afterwards into the milestones below, so each capability has a focused commit and explanatory message.

These are **reconstructed milestones, not previously existing commits or exact historical snapshots**. Shared entrypoints, version declarations and schema dispatch were separated retrospectively to keep intermediate revisions usable. Later corrections present in the workspace can appear in the corresponding feature commit. The final tree is the reviewed working implementation.

Git **author dates** approximate the original development milestone using local file creation/modification timestamps and the session chronology. Git **committer dates** record when the commits were actually created for publication. All original development milestones are on the same date; no earlier days have been invented.

The commits contain source, schemas, examples, documentation and tests. Evaluation databases, local reports/transcripts, private configuration, credentials, generated environments and dependency directories are excluded. Automated respondent fixtures are synthetic and do not establish human or real-model performance. Solana RPC coverage in the default suite is mocked; publishing this repository does not issue an agent passport or submit a blockchain transaction.
