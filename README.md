# Epistemics

Behavioral epistemic evaluation with auditable reports and agent identity records. Reported probabilities are observations, not direct access to private beliefs.

The 88-trial numeric evaluator and persistent stdio MCP interface are available.

## Development

Use `uv sync --locked`. Run `mise run check` for the offline checks.

Start the numeric evaluator with `uv run epistemics-mcp`; `uv run epistemics demo` runs a synthetic reference respondent.

This commit is a retrospectively assembled development milestone. Historical author dates approximate the original work; commit dates record creation of this history. No original commits existed before publication.
